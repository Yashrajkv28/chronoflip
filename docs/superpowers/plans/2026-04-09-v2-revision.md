# ChronoFlip v2 Revision Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement client revision requests — venue name, button labels, timer grouping with group-aware start/restart/navigation, and sync support for viewers.

**Architecture:** Flat segments array with optional `groupId` field. Consecutive segments with the same `groupId` form visual groups. Groups metadata (id + name) stored on the event. TimerRunningScreen receives group context to scope restart and enable prev/next group navigation.

**Tech Stack:** React 19, TypeScript, Tailwind CSS, AWS AppSync GraphQL, DynamoDB (via Amplify client)

**Spec:** `docs/superpowers/specs/2026-04-09-v2-revision-design.md`
**AWS Change Guide:** `yash.md`

- [ ] **Step 5: Update EventSettingsScreen segment list to render groups**

Replace the segment list rendering section (~line 290-322) with group-aware rendering. This is the core logic that detects consecutive `groupId` runs and renders them as group blocks:

```tsx
{/* Segment List — group-aware rendering */}
<div className="flex-1 overflow-y-auto px-4 sm:px-6 pb-6">
  <div className="max-w-2xl mx-auto space-y-2">
    {event.segments.length === 0 ? (
      <div className="text-center py-16">
        <p className="text-zinc-500 text-sm">
          No segments yet. Tap + New Timer to add one.
        </p>
      </div>
    ) : (
      <DndContext
        sensors={sensors}
        collisionDetection={closestCenter}
        onDragEnd={handleDragEnd}
      >
        {(() => {
          // Build display items: interleaved loose segments and groups
          const items: Array<
            | { type: 'segment'; segment: Segment; index: number }
            | { type: 'group'; groupId: string; segments: { segment: Segment; index: number }[] }
          > = [];

          let i = 0;
          while (i < event.segments.length) {
            const seg = event.segments[i];
            if (seg.groupId) {
              // Collect consecutive segments with same groupId
              const groupId = seg.groupId;
              const groupSegs: { segment: Segment; index: number }[] = [];
              while (i < event.segments.length && event.segments[i].groupId === groupId) {
                groupSegs.push({ segment: event.segments[i], index: i });
                i++;
              }
              items.push({ type: 'group', groupId, segments: groupSegs });
            } else {
              items.push({ type: 'segment', segment: seg, index: i });
              i++;
            }
          }

          return items.map((item, idx) => {
            if (item.type === 'segment') {
              return (
                <SegmentCard
                  key={item.segment.id}
                  segment={item.segment}
                  editMode={editMode}
                  onEdit={() => onEditSegment(item.segment.id)}
                  onStart={() => onStartEvent(item.index)}
                  onDelete={() => onDeleteSegment(item.segment.id)}
                  swipeOpenId={swipeOpenId}
                  onSwipeOpen={setSwipeOpenId}
                />
              );
            } else {
              const group = event.groups?.find(g => g.id === item.groupId);
              if (!group) return null; // orphaned groupId — skip
              return (
                <GroupBlock
                  key={group.id}
                  group={group}
                  segments={item.segments.map(s => s.segment)}
                  editMode={editMode}
```
